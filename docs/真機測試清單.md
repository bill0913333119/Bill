# 真機測試清單

部署到 HTTPS 網址後，用 **Android（Chrome）** 與 **iPhone（Safari）** 各跑一次。
每項打 ✅／❌，❌ 請截圖並記下手機型號與作業系統版本。

## 事前準備

- [ ] 網址為 `https://` 開頭（否則相機、麥克風、分享都不會動）
- [ ] 設定頁填好工程師姓名、預設專案
- [ ] 建一個測試用 LINE 群組（自己＋一位同事即可）

## H. 工人進場報到與吹哨

需兩支手機：一支當工人、一支當安衛人員（工程師 App 輸入 `SAFETY_TOKEN`）。

| # | 操作 | 預期結果 | Android | iPhone |
|---|---|---|---|---|
| H1 | 安衛：🦺 工安 → 設定 → 下載海報，印出 | A4 海報上的 QR 清楚可掃 | | |
| H2 | 工人：用手機相機掃海報 QR | 開啟「第一次進場，請登錄資料」 | | |
| H3 | 工人：用 LINE 的「掃描 QR Code」掃 | 在 LINE 內開啟同一頁 | | |
| H4 | 工人：登錄後完成 5 步驟報到 | 首頁顯示「今日已報到」與工區 | | |
| H5 | 工人：把安衛訓練效期改成昨天，再報到 | 第 2 步被擋下，安衛「今日」看到被擋名單 | | |
| H6 | 安衛：人員名冊 → 核驗工班長 | 工班長首頁出現「本工班待改善」 | | |
| H7 | 工人：工安隨手拍（臨時用電、A 級） | 顯示已通知的工班與 2 小時期限；水電工班長手機的「本工班待改善」出現此件 | | |
| H8 | 工人：匿名吹哨 | 顯示回執碼；工程師金鑰看不到內容，安衛金鑰看得到 | | |
| H9 | 安衛：審核 → 派工 | 吹哨者用回執碼查詢，狀態變成「待改善」 | | |
| H10 | 工班長：本工班待改善 → 拍改善後照片 → 送出 | 左右對照顯示；安衛「追蹤」中狀態變成待複查 | | |
| H11 | 安衛：通過並銷案 | 具名通報人的點數增加 | | |
| H12 | 地下室（飛航模式）送出隨手拍，再恢復網路 | 首頁顯示「已補送」 | | |
| H13 | 隔天：有未銷案 A 級缺失的工班到同一工區報到 | 被管制擋下；安衛解鎖後可報到 | | |
| H14 | 有 LINE 群組綁定時，A 級通報放 2 小時不處理 | 群組收到「逾時未改善升級通報」 | | |
